What happens when a level is set

One path for clicks and keys. A locked role never changes; it shakes the rail and keeps focus where it was.

Why the shake keeps focus

The rail swaps between two identical keyframes (shake / shake again) instead of remounting, so the focused stop stays in the DOM.

Keys

Left/Down go down a level, Right/Up go up, Home and End jump to None and Manage.

Clicks

The browser already focuses the clicked stop, so only keys move focus.
