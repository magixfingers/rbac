How data moves through Roles

Two copies of the roles live in state: the working copy you edit and the saved snapshot. Everything you see is derived from the two on each render.

Two copies, one diff

Every unsaved marker (dots, the count in the bar) comes from comparing roles with saved. Nothing tracks edits as they happen, so an edit undone by hand stops counting by itself.

Props are read once

roles and selected seed state on mount. Changing them afterwards does nothing; remount with a new key to reset.

Save is a copy

After 650 ms, saved becomes the working roles and onSave gets the same array.
